### Causa do Erro HTTP 403:
O Access Token provavelmente expirou. O token da Shopee tem validade de ~4 horas.

### Soluções Possíveis:
1. **Reautorizar a loja** (fluxo completo):
   - Clique em "Linkar Loja" 
   - Faça login na Shopee
   - Autorize a loja
   - Copie o code da URL
   - Cole em "Código de Autorização"
   - Clique em "Finalizar Login"

2. **Verificar se WARP/VPN está desativado** (usuario já fez isso)

3. **Verificar se as credenciais no servidor estão atualizadas**

### Fluxo de Autenticação Shopee:
1. Partner ID + Partner Key → Gerar URL de autorização
2. Usuário autoriza → Recebe código
3. Código → Trocar por Access Token + Refresh Token
4. Access Token expira em ~4 horas
5. Refresh Token → Obter novo Access Token
